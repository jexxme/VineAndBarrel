本页会告诉你一晚上的每一种收场方式。想自己去发现的话，就到这里为止吧：[微醺](/tipsy/#多喝一杯)页只给了一点暗示。

已经在微醺 {roman(t.maxLevel - 1)} 还继续喝？再来一杯，过一小会儿你就会**断片**。它无害：你的东西一件都不会丢，醒来的地方永远安全，时间不会流逝，也不影响其他人。服主可以用 `blackout` 选项把它关掉（见[配置](/reference/config/)）。

## 过程

<Steps>

1. **后劲上来了**。多喝的那一杯会在 {Math.round(under.soonestTicks / 20)} 到 {Math.round(under.latestTicks / 20)} 秒后才上头，不管你那时正在干什么。最后 {Math.round(under.ticks / 20)} 秒里，你会觉得自己在往下沉：眼皮越来越沉，脑袋耷拉下来，周围的声音又闷又远，腿一软，身子晃得厉害。朋友们也看得出你快撑不住了。在后劲上来之前醒酒（一桶牛奶、睡一整晚），就能躲过去；再喝一杯也没法把它往后推。
2. **你倒下了**。眼睛一闭，你像一棵被砍倒的树，直挺挺地脸朝下栽倒。周围的人都看到你躺在那里，星星绕着你的脑袋转。
3. **一片漆黑**。几秒钟里你动不了，微醺也不来打扰你：腿不再打晃，也不再打嗝。也没人能伤到你，无论是生物还是玩家，摔倒本身也不会。只有任何人躺在那里都会受到的伤害仍然有效，比如熔岩或虚空，所以你在哪里断片很重要；而你*醒来*的地方永远是安全的。
4. **你在某处醒来**。屏幕还黑着的时候，游戏会选好你这一晚的收场地点（见下文），把你放在那里：躺在地上、躺在床上，或坐在船里。你慢慢睁开眼，然后起身；要是躺在地上，你会撑着地爬起来。
5. **屏幕上出现一行字**，说明刚才是怎么回事，比如 *{gameText(b.endings.find((e) => e.id === 'in_the_hay')?.lineKeys[0], b.endings.find((e) => e.id === 'in_the_hay')?.lines[0])}*，或者其他很多种。

</Steps>

从倒下到醒来大约持续 {seconds(b.ticks)}。醒来时：

- **酒醒了，却带着宿醉**，持续 {duration(h.afterBlackoutTicks)}（日光刺眼，响声让你一激灵；见[第二天早上](/tipsy/#第二天早上)），饮品给你的增益也没了，
- **饿了**：饥饿格最多只剩 {h.hungryFood / 2} 个，饱和度清零，
- **口袋里多了一件纪念品**，和你醒来的地方有关（口袋满了就掉在脚边），
- 另外，有 {b.pumpkinOneIn} 分之一的几率，**头上多了一个雕刻南瓜**，前提是你没戴头盔。

如果服务器关掉了 `hangover` 选项，你醒来时会回到微醺 I，并且少了 {b.hungerLost / 2} 个饥饿格。

## 你会在哪里醒来

一晚上有 {count} 个可能的收场地点，外加一个所有地点都不成立时的备选。每个地点都有自己的概率，但只有在你断片的位置可行的才会参与抽取：附近没有水就没有船，没有村庄就没有酒馆。

- **新的优先**：你还没经历过的收场，概率是已经经历过的 {b.unseenBonus} 倍。
- **不会连续两次相同**，除非没有别的可能。
- **永远安全**：脚下是实地，有站立的空间，没有熔岩或水，旁边没有会烧伤或扎人的东西，{b.ranges.monsterFree} 格内没有怪物，也在世界边界之内。
- **绝不在别人的建筑里**：户外的收场都需要头顶是开阔的天空（玻璃和树叶也算遮挡）。两个室内收场只使用世界为所有人建好的东西，即村庄酒馆和村庄房屋里村民的床，以及你自己的床。
- **在下界和末地**没有开阔的天空，所以大多数夜晚就在你倒下的地方收场。

下面的概率是第一次断片、所有收场都可行时的情况。之后概率会变化：你还没经历过的收场更容易出现，而刚经历过的会让位。

## 集齐

第一次断片会获得*我在哪？*。在全部 {count} 个地点都醒来一次（*就地*不算），就能完成挑战*失去的周末*。游戏会记住你经历过哪些，即使死亡也不会忘。

<Aside type="tip" title="想要某个特定的收场？">
在最后一杯之前先布置好场地：附近有自己的床，对应*在家*；户外有一堆干草或<Item id="barley_bale" />，对应*在干草堆里*；有一个池塘，对应*在船上*；有带酒馆的村庄，对应室内的两个。已经经历过的收场概率更低，所以稀有的会比你想的更快出现。
</Aside>
