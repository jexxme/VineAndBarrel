Vine & Barrel has two config files, both about [Tipsy](/tipsy/). Everything else, from recipes to how long a barrel
takes, works the way the mod ships and can be changed with a datapack like any recipe.

In game, change them on the settings screen: **Mods**, Vine & Barrel, **Config** on NeoForge; on Fabric the same button
appears with [Mod Menu](https://modrinth.com/mod/modmenu) installed. Changes there apply at once. The server options
show there in singleplayer (not once the world is open to LAN); on a server they are the server's.

The files themselves: on NeoForge they are TOML files with the options under <code>[{configFiles.server.section}]</code>. On
Fabric they are plain <code>.properties</code> files in the <code>config</code> folder, with the same options written as
<code>{configFiles.server.section}.option=value</code>. On Fabric the client file is read when the game starts, so
restart after editing it; the server file is read again on <code>/reload</code>.

## Server options

In <code>{configFiles.server.file}</code> on NeoForge, <code>{configFiles.server.fabricFile}</code> on Fabric. The server's
values go to every player who joins, so everyone plays by the same rules. One world can have its own: put the file into
that world's <code>serverconfig</code> folder, and it wins over the one in <code>config</code> while that world runs.

<Aside title="Non-alcoholic mode">
Set `enabled = false` (`tipsy.enabled=false` on Fabric) and drinks become plain buff drinks: no Tipsy, no hiccups, no blackouts, but the same names and buffs.
Good for a family server, or if you simply don't like the wobble.
</Aside>

## Client options

In <code>{configFiles.client.file}</code> on NeoForge, <code>{configFiles.client.fabricFile}</code> on Fabric. Each player
sets these for themselves; they only change what you see.

<Aside type="tip" title="Motion sickness?">
Set "Drunk screen" to 0 % (`drunkScreen = 0`, `tipsy.drunkScreen=0` on Fabric). Tipsy never moves your screen on its own, and at 0 a hiccup, a stumble or a trip doesn't move it either, whatever the server says. Vanilla's Distortion Effects slider tones it down too, and its Darkness Pulsing slider tones down the sinking lids when you nod off. Lying on your face after a trip still shows, it isn't a screen effect. If double vision bothers you, switch off "Double vision" (`doubleVision = false`); everything else about Tipsy stays.
</Aside>
