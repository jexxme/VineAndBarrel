Vine & Barrel은 포도밭과 양조장, 그리고 저장고를 Minecraft에 가져옵니다. 포도, 홉, 보리를 키우고, 구리 솥에서 주스와
맥아즙을 만들고, 참나무 통에서 발효와 숙성을 시킨 다음, 친구들과 한 잔씩 나눠요. 기다린 만큼 보상이 있어요. 숙성된 술은
버프가 더 강하고 더 오래 가며, 잔 속에서 반짝여요.

## 설치

Minecraft 버전과 로더를 찾아서, 해당 칸에서 내려받으세요.

<table>
	<thead><tr><th>Minecraft</th><th>NeoForge</th><th>Fabric</th></tr></thead>
	<tbody>
		{downloads.map((r) => (
			<tr>
				<td>{r.minecraft}</td>
				<td>{cell(r.neoforge)}</td>
				<td>{cell(r.fabric)}</td>
			</tr>
		))}
	</tbody>
</table>

- **NeoForge** 필요 버전: {downloads.map((r) => `Minecraft ${r.minecraft}에서 NeoForge ${(r.neoforgeNeeds ?? `${meta.neoforge} or newer`).replace(' or newer', ' 이상')}`).join('; ')}.
- **Fabric** 필요 버전: Fabric Loader {meta.fabricLoader} 이상, Fabric API {meta.fabricApi} 이상.

파일 이름을 보면 어느 쪽인지 알 수 있어요. <code>VineAndBarrel-{meta.minecraft}-{meta.modVersion}.jar</code>은 NeoForge용,
<code>VineAndBarrel-{meta.minecraft}-{meta.fabricModVersion}.jar</code>은 Fabric용입니다. 클라이언트와 서버 모두 `mods` 폴더에 넣으세요. 다른 모드는
필요 없어요. 함께 쓸 수 있는 모드는 전부 선택 사항이고 알아서 켜집니다. [호환성](/compatibility/)을 참고하세요.

<Aside type="tip" title="Farmer's Delight와 함께 하나요?">
Vine & Barrel은 독립된 모드지만 FD와 잘 어울려요. 솥은 FD의 난로 위에서도 양조하고, 포도와 홉 덩굴은 FD의 밧줄을 타고 올라가고,
조리용 냄비 요리 몇 가지와 잔치 요리, 빵에는 이 모드의 술이 들어갑니다. [Farmer's Delight](/farmers-delight/)를 참고하세요.
</Aside>

## 어디서 시작할까요

- **모드가 처음인가요?** [첫 번째 술](/guides/first-drink/)을 따라 해 보세요. 새 월드에서 첫 숙성 레드 와인 한 잔까지 한 걸음씩 안내해요.
- **한꺼번에 많이 만들 준비가 됐나요?** [저장고 짓기](/guides/cellar/)에서 통 선반, 자동화, 배치 계획을 다뤄요.
- **급한가요?** 마을 선술집을 찾아가세요. 통이 가득 차서 따르기만 하면 돼요. [마을과 선술집](/villages/)을 참고하세요.
- **읽기보다 보는 게 좋은가요?** 게임 안에서 툴팁이 "G 키로 보기"로 끝나면 짧은 장면이 있어요. 아이템 위에서, 또는 블록을 바라보며 G를 누르면 누군가 한 단계씩 대신 만들어 줘요. G는 조작에서 바꿀 수 있어요.
- **뭔가 찾아보고 싶나요?** 모든 아이템은 [모든 아이템과 블록](/items/)에 각자의 페이지가 있고, 모든 레시피는 [모든 레시피](/reference/recipes/)에, 서버와 클라이언트 옵션은 [설정](/reference/config/)에 있어요.
