import { Steps, Aside } from '@astrojs/starlight/components';
import Item from '../../../../components/mc/Item.astro';
import Render from '../../../../components/mc/Render.astro';
import Recipe from '../../../../components/recipes/Recipe.astro';
import Stages from '../../../../components/data/Stages.astro';
import WildCrops from '../../../../components/data/WildCrops.astro';
import EffectBadge from '../../../../components/data/EffectBadge.astro';
import { rules, recipe, drinks, days, seconds, duration, roman } from '../../../../lib/l10n/ko';

export const juice = recipe('brewing/grape_juice');
export const wine = recipe('aging/red_wine');
export const young = drinks.find((d) => d.id === 'vineandbarrel:red_wine');
export const aged = drinks.find((d) => d.id === 'vineandbarrel:aged_red_wine');
export const h = rules.harvest;
export const grapesPerBatch = juice.ingredients.filter((g) => g.items.includes('vineandbarrel:red_grapes')).length;

<Render name="scenes/tavern" float="right" size={230} alt="통과 술이 놓인 탁자가 있는 선술집 한구석" />

이 가이드는 새 월드에서 시작해 첫 레드 와인 한 잔을 만들고, 이어서 숙성된 와인까지 안내해요. 시작할 때는 바닐라
재료만 있으면 되고, 포도는 가는 길에 구하게 돼요. 각 단계에서 자세한 내용이 담긴 페이지로 연결돼요.

<Steps>

1. **야생 포도를 찾으세요.** 야생 식물은 월드 곳곳에 무리 지어 자라고, 종류마다 자라는 곳이 달라요. 와인을 만들려면
   <Item id="wild_grapes" />가 필요해요. 손으로 하나 부수면 <Item id="red_grapes" plural />가 나와요.

   <WildCrops />

   못 찾겠나요? 마을 농부와 떠돌이 상인이 포도를 팔고, 마을 상자에도 종종 들어 있어요.
   [마을과 선술집](/villages/)을 참고하세요.

2. **덤불을 몇 그루 심으세요.** 달콤한 열매처럼 잔디, 흙, 경작지에 포도를 심으세요. 덤불은 저절로 자라요.
   다 익으면 우클릭해서 포도 {h.grapes.count[0]}~{h.grapes.count[1]}개를 따요. 덤불은 한 단계 되돌아가 다시
   열매를 맺으니 다시 심을 필요가 없어요. 뼛가루를 쓰면 더 빨리 자라요.

   <Stages prefix="grape_bush" title="자라는 적포도 덤불" labels={['심음', '성장 중', '반쯤 익음', '익음']} />

   주스 한 배치에는 포도 {grapesPerBatch}개와 설탕 하나가 들어가요. 처음에는 덤불 몇 그루면 충분해요.
   자세한 내용은 [작물](/crops/)에 있어요.

3. **양조 솥을 만들어 불 위에 놓으세요.** <Item id="brew_kettle" />은 구리로 만들어요. 바로 아래 블록이 뜨거울
   때만 양조하는데, 불을 붙인 모닥불이면 처음부터 쓸 수 있어요. 솥은 철 받침대 위에서 불꽃 위에 서 있어요.

   <div class="not-content" style="display:flex;flex-wrap:wrap;gap:30px 40px"><Recipe id="brew_kettle" /></div>

4. **적포도 주스를 양조하세요.** 솥을 우클릭해 열고 포도 {grapesPerBatch}개와 설탕 하나를 넣으세요. 솥이 달궈지는
   동안 화살표가 차오르고, 뚜껑 밑으로 김이 새어 나오고, {seconds(juice.brewingTime)} 뒤에는 게이지에
   <Item id="grape_juice" /> {juice.servings}인분이 표시돼요. 재료를 더 넣으면 계속 이어서 양조해요.
   [양조 솥](/brew-kettle/)을 참고하세요.

   <div class="not-content"><Recipe id="brewing/grape_juice" /></div>

5. **꺼내세요.** 유리병으로 솥을 우클릭하면 1인분, 양동이로 하면 {rules.servingsPerBucket}인분을 담아요.
   적포도 주스는 그 자체로 음료예요. [알딸딸함](/tipsy/)을 가라앉혀 줘요.

6. **숙성 통을 채우세요.** <Item id="aging_barrel" />을 놓고 양동이나 병으로 우클릭하세요. 통에는
   {rules.barrelCapacity}인분이 들어가니, 양동이 두 개면 가득 차요. 발효 중에 같은 주스를 더 붓는 것도 괜찮아요.

   <div class="not-content"><Recipe id="aging_barrel" /></div>

7. **발효를 기다리세요.** **{days(wine.fermentingTime)}**이 지나면 주스가 <Item id="red_wine" />이 돼요. 통이
   상태를 알려 줘요. 발효 중에는 위에 달린 유리 에어락에서 거품이 올라오고, 빈손으로 우클릭하면 *레드 와인 · 8인분 · 발효 중, 내일 아침 완료*
   같은 상태 줄이 나와요. 시간은 게임 시간으로 흐르니, 밤에 잠을 자도 계산돼요. [숙성 통](/aging-barrel/)을 참고하세요.

8. **잔에 따르세요.** 빈 <Item id="wine_glass" />으로 통을 우클릭하면 1인분을 따라요. 와인은 와인잔에,
   맥주, 벌꿀술, 사이더는 <Item id="mug" />에 따라요. 잔을 잘못 들면 통이 알려 줘요.

   <div class="not-content"><Recipe id="wine_glass" /></div>

9. **마시세요.** <Item id="red_wine" />을 마시면 <EffectBadge id={young.effect.id} name={young.effect.name} ticks={young.effect.duration} amplifier={young.effect.amplifier} /> 버프와
   <EffectBadge id="vineandbarrel:tipsy" name="알딸딸함" /> 한 단계가 붙어요. 잔은 그대로 돌려받아요. 근처의 친구와 같은 순간에
   마시면 **건배!**가 돼서, 모두의 버프가 {rules.cheersBonusPercent}% 더 오래 가요. 선술집 주인 앞에서 다 마시면
   주인도 잔을 부딪쳐 줘요.

10. **나머지는 숙성시키세요.** 통을 **{days(wine.agingTime)}** 더 그대로 두면 남은 술이
    <Item id="aged_red_wine" />이 돼요. 더 짙은 붉은색으로 반짝이고, 버프는 <EffectBadge id={aged.effect.id} name={aged.effect.name} ticks={aged.effect.duration} amplifier={aged.effect.amplifier} />로 바뀌어요.
    코르크가 살짝 뻥 터지는 소리와 위쪽의 붉은 밀랍 봉인이 다 됐다는 신호예요.

</Steps>

<Aside type="tip" title="못 기다리겠나요?">
숙성 단계에서 따른 잔은 그만큼 숙성될 술이 줄어든다는 뜻이에요. 통을 두 개 채워서 하나에서는 마시고, 다른 하나는
숙성될 때까지 그대로 두세요. 아니면 마을 선술집을 찾아가세요. 통이 이미 가득 차 있고, 몇 개는 숙성까지 끝나 있어요.
[마을과 선술집](/villages/)을 참고하세요.
</Aside>
