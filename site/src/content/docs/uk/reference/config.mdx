export const value = (o) => String(exported[o.key] ?? o.fallback);

Vine & Barrel має два файли налаштувань, обидва про [«Напідпитку»](/tipsy/). Усе інше, від рецептів до тривалості витримки
в діжці, працює так, як постачається з модом, і змінюється датапаком, як і будь-який рецепт (на Minecraft 1.21.1 і 1.20.1 усе, крім торгівлі з селянами).

У грі їх змінюють на екрані налаштувань: **Моди**, Vine & Barrel, **Конфіг** на NeoForge; на Fabric така сама кнопка
з'являється, якщо встановлено [Mod Menu](https://modrinth.com/mod/modmenu). Зміни там діють одразу. Серверні параметри
видно там в одиночній грі (не тоді, коли світ відкрито для локальної мережі); на сервері вони належать серверу. На Forge (Minecraft 1.20.1) такої кнопки
немає: редагуй файли.

Самі файли: на NeoForge і Forge це файли TOML з параметрами під <code>[{configFiles.server.section}]</code>. На
Fabric це звичайні файли <code>.properties</code> у теці <code>config</code>, ті самі параметри записано як
<code>{configFiles.server.section}.option=value</code>. На Fabric клієнтський файл читається під час запуску гри, тож
перезапусти її після редагування; серверний файл перечитується командою <code>/reload</code>.

## Серверні параметри

У <code>{configFiles.server.file}</code> на NeoForge і Forge, <code>{configFiles.server.fabricFile}</code> на Fabric. Значення сервера
отримує кожен гравець, що приєднується, тож усі грають за однаковими правилами. Один світ може мати свої: поклади файл у
теку <code>serverconfig</code> цього світу, і він переважатиме файл із <code>config</code>, поки цей світ працює.

<table>
	<thead><tr><th>Параметр</th><th>Типово</th><th>Що робить</th></tr></thead>
	<tbody>
		{rows(configFiles.server).map((o) => (
			<tr id={`opt-${o.key}`} class="ref-target">
				<td><code>{o.key}</code></td>
				<td><code>{o.def}</code>{o.range && <><br /><span class="soft">від {o.range[0]} до {o.range[1]}</span></>}</td>
				<td>{o.what.split('`').map((part, i) => (i % 2 ? <code>{part}</code> : part))}</td>
			</tr>
		))}
	</tbody>
</table>

<Aside title="Безалкогольний режим">
Постав `enabled = false` (`tipsy.enabled=false` на Fabric), і напої стануть простими напоями з бонусами: без «Напідпитку», без гикавки, без провалів у пам'яті, але з тими самими назвами й бонусами.
Добре для сімейного сервера або якщо тобі просто не подобається хитання.
</Aside>

## Клієнтські параметри

У <code>{configFiles.client.file}</code> на NeoForge і Forge, <code>{configFiles.client.fabricFile}</code> на Fabric. Кожен гравець
налаштовує їх для себе; вони змінюють лише те, що бачиш ти.

<table>
	<thead><tr><th>Параметр</th><th>Типово</th><th>Що робить</th></tr></thead>
	<tbody>
		{rows(configFiles.client).map((o) => (
			<tr id={`opt-${o.key}`} class="ref-target">
				<td><code>{o.key}</code></td>
				<td><code>{o.def}</code>{o.range && <><br /><span class="soft">від {o.range[0]} до {o.range[1]}</span></>}</td>
				<td>{o.what.split('`').map((part, i) => (i % 2 ? <code>{part}</code> : part))}</td>
			</tr>
		))}
	</tbody>
</table>

<Aside type="tip" title="Заколисує?">
Постав «П'яний екран» на 0 % (`drunkScreen = 0`, `tipsy.drunkScreen=0` на Fabric). «Напідпитку» ніколи не рухає екран сам по собі, а на 0 його не смикають ні гикавка, ні спотикання, ні падіння, що б не казав сервер. Ванільний повзунок «Ефекти викривлення» теж це послаблює, а повзунок «Пульсація темряви» послаблює повіки, що опускаються, коли ти клюєш носом. Те, що ти лежиш долілиць після падіння, лишається, це не ефект екрана. Якщо тобі заважає двоїння в очах, вимкни «Двоїться в очах» (`doubleVision = false`); усе інше в «Напідпитку» залишається.
</Aside>
