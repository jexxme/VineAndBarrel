すでにほろ酔い {roman(t.maxLevel - 1)} なのにまだ飲む? もう一杯飲むと、少しして**記憶が飛びます**。害はありません。持ち物は失われず、
危ない場所で目覚めることもなく、時間も進まず、ほかの人には影響しません。サーバー管理者は`blackout`オプションでオフにできます
([設定](/reference/config/)を参照)。

## 何が起きるか

<Steps>

1. **あとから効いてくる。** 飲みすぎた一杯は、{Math.round(under.soonestTicks / 20)}〜{Math.round(under.latestTicks / 20)}秒後に効いてきます。
   そのとき何をしていてもです。最後の{Math.round(under.ticks / 20)}秒間は、沈んでいくのが自分でわかります。まぶたが重くなり、頭が垂れ、
   世界の音がこもって遠のき、足から力が抜けて、体が大きく揺れます。友だちにも、それが来るのが見えます。効いてくる前に酔いを覚ませば
   (ミルク入りバケツ、一晩の睡眠)、記憶は飛びません。もう一杯飲んでも先送りにはなりません。
2. **倒れる。** 目が閉じて、そのまま倒れます。周りの人には、横たわるあなたと、頭の上をぐるぐる回る星が見えます。
3. **暗転。** 数秒間は動けませんが、ほろ酔いも手加減してくれます。ふらつく足も、しゃっくりもありません。モブもプレイヤーも、
   倒れたこと自体も、あなたを傷つけられません。そこに寝ている誰にとっても痛いもの、たとえば溶岩や奈落だけは普通に効くので、
   気を失う場所は大事です。ただし、*目覚める*場所は必ず安全です。
4. **どこかで目覚める。** 画面がまだ暗いうちに、ゲームが夜の終わった場所を決めて(下を参照)、あなたをそこに運びます。
   地面に寝ているか、ベッドの中か、ボートに座っています。ゆっくり目が開き、そして起き上がります。
5. **画面に一行。** 夜がどうだったかを伝えます。*{gameText(b.endings.find((e) => e.id === 'in_the_hay')?.lineKeys[0], b.endings.find((e) => e.id === 'in_the_hay')?.lines[0])}*のようなものから、ほかにもいろいろあります。

</Steps>

倒れてから目覚めるまで約{seconds(b.ticks)}かかります。目覚めたとき:

- **素面ですが二日酔い**が{duration(h.afterBlackoutTicks)}続きます(日の光がまぶしく、大きな音に顔をしかめます。
  [翌朝](/tipsy/#翌朝)を参照)。飲み物でもらった強化効果もなくなっています。
- **空腹:** 空腹ゲージは{h.hungryFood / 2}個分までしかなく、隠し満腹度もゼロです。
- **おみやげ**がポケットに入っています。目覚めた場所にふさわしいものです(ポケットがいっぱいなら足元に)。
- そして{b.pumpkinOneIn}回に1回は、ヘルメットをかぶっていなければ**頭にくり抜かれたカボチャ**がのっています。

サーバーの`hangover`オプションがオフなら、代わりにほろ酔い I で目覚め、空腹ゲージが{b.hungerLost / 2}個分減っています。

## 目覚める場所

夜の終わり方は{count}か所あり、どれもだめだった場合のための1つもあります。それぞれに確率がありますが、くじに入るのは
気を失った場所で可能なものだけです。近くに水がなければボートはなし、村がなければ酒場もありません。

- **新しいものが先:** まだ経験していない結末は、経験した結末の{b.unseenBonus}倍出やすくなります。
- **同じものが2回続くことはありません。** ほかに選べるものがない場合は別です。
- **必ず安全:** 固い地面、立てる広さ、溶岩や水がなく、近くに燃えるものや刺さるものがなく、
  {b.ranges.monsterFree}ブロック以内にモンスターがおらず、ワールドボーダーの内側です。
- **人の建築物の中にはなりません:** 屋外の結末は、頭上が開けた空である必要があります(ガラスや葉もだめ)。屋内の2つは、
  世界がみんなのために作ったもの、つまり村の酒場と村の家にある村人のベッド、それに自分のベッドだけを使います。
- **ネザーとジ・エンド**には開けた空がないので、ほとんどの夜は倒れたその場所で終わります。

下の確率は、すべての結末が可能な場合の最初の記憶飛びのものです。その後は変わっていきます。まだ経験していない結末は出やすくなり、
今経験したばかりのものは順番を譲ります。

## 全部集めよう

最初の記憶飛びで*ここはどこ？*がもらえます。{count}か所すべてで目覚める(*その場*は数えません)と、チャレンジ
*失われた週末*です。どこを経験したかはゲームが覚えていて、死んでも消えません。

<Aside type="tip" title="狙いの結末がある?">
最後の一杯の前に舞台を整えましょう。*我が家*なら近くに自分のベッド、*干し草の中*なら屋外に干し草か<Item id="barley_bale" />の山、
*ボートの上*なら池、屋内の結末なら酒場のある村です。経験済みの結末は出にくくなるので、珍しいものは思ったより早く出ます。
</Aside>
