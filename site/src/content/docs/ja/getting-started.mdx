Vine & Barrel は、ブドウ園と醸造所とワインセラーをMinecraftに持ち込みます。ブドウ、ホップ、大麦を育て、銅の釜でジュースや麦汁を醸造し、
オークの樽で発酵、熟成させて、仲間と一杯やりましょう。待った分だけ報われます。熟成した飲み物は強化効果が強く、長く続き、
グラスの中できらめきます。

## インストール

Minecraft のバージョンとローダーを選んで、そのセルからダウンロードします。

- **NeoForge** には {downloads.map((r) => `Minecraft ${r.minecraft} 用に NeoForge ${r.neoforgeNeeds?.replace(' or newer', ' 以降') ?? `${meta.neoforge} 以降`}`).join('、')} が必要です。
- **Fabric** には Fabric Loader {meta.fabricLoader} 以降と Fabric API {meta.fabricApi} 以降が必要です。

ファイル名でどちらか分かります。<code>VineAndBarrel-{meta.minecraft}-{meta.modVersion}.jar</code> は NeoForge、
<code>VineAndBarrel-{meta.minecraft}-{meta.fabricModVersion}.jar</code> は Fabric です。クライアントにもサーバーにも `mods` フォルダーに入れてください。
ほかの Mod は必要ありません。連携する Mod はすべて任意で、自動的に有効になります。詳しくは[互換性](/compatibility/)をご覧ください。

<Aside type="tip" title="Farmer's Delight と一緒に遊びますか?">
Vine & Barrel は独立した Mod ですが、Farmer's Delight とよくなじみます。醸造釜は FD のコンロで醸造でき、ブドウとホップのつるは FD のロープを登り、
いくつかの鍋料理とごちそう、パンがこの Mod の飲み物を使います。[Farmer's Delight](/farmers-delight/)をご覧ください。
</Aside>

## どこから始めるか

- **初めてですか?** [はじめての一杯](/guides/first-drink/)をどうぞ。新しいワールドから熟成赤ワインの最初の一杯まで、順を追って進みます。
- **まとめて醸造したい?** [セラーを作る](/guides/cellar/)で、樽のラック、自動化、バッチの計画を扱います。
- **急ぎですか?** 村の酒場を探しましょう。樽は満タンで、注がれるのを待っています。[村と酒場](/villages/)をご覧ください。
- **読むより見たい?** ゲーム内でツールチップの最後に「Gキーで見る」とあれば、短いシーンがあります。アイテムの上で、またはブロックを見ながらGキーを押すと、誰かが順を追って醸造してくれます。Gキーは「操作設定」で変更できます。**醸造家の道**では、ブドウの木からグラスまでの全行程が見られ、済んだところにチェックが付きます。シーンのないものを見ながらGキーを押すか、シーンの中で道のアイコンをクリックしてください。
- **調べものですか?** アイテムごとのページは[すべてのアイテムとブロック](/items/)に、レシピは[すべてのレシピ](/reference/recipes/)に、サーバーとクライアントの設定は[設定](/reference/config/)にあります。
